A café sells coffee in three sizes. Write a program that asks for a size and prints its price:

| The customer types | Print |
|--------------------|-------|
| `S` | `Small coffee: 2` |
| `M` | `Medium coffee: 3` |
| `L` | `Large coffee: 4` |
| anything else | `Sorry, we only have S, M and L.` |

```text
Size (S, M or L): M
Medium coffee: 3
```

Put the question inside `input()`, as in the sample run, so your program prints only the price line.
The sizes are capital letters.
