Write a program that asks which times table to show, then prints it from 1 to 10. For example, when
someone types 7:

```text
Which times table? 7
1 x 7 = 7
2 x 7 = 14
3 x 7 = 21
4 x 7 = 28
5 x 7 = 35
6 x 7 = 42
7 x 7 = 49
8 x 7 = 56
9 x 7 = 63
10 x 7 = 70
```

Pass the question to `input()` rather than printing it, so that the ten lines of the table are all your
program prints. Use a loop, not ten `print` lines, so that it works for any number.
