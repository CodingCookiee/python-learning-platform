A group of friends at a restaurant want to split the bill equally. Write `split_bill(total, people)`
that **returns** each person's share, rounded to 2 decimal places:

| Call | Returns |
|------|---------|
| `split_bill(60, 4)` | `15.0` |
| `split_bill(100, 3)` | `33.33` |

Return the share rather than printing it: the tests call your function and check what it hands back.
Replace the `...` in the starting code with your own lines.
