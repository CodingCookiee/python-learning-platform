A shop plays the same announcement twice before it closes. Write a function called `announce` that
prints these two lines:

```text
Attention, shoppers!
The shop closes in 10 minutes.
```

Then call `announce` twice, so that the whole program prints:

```text
Attention, shoppers!
The shop closes in 10 minutes.
Attention, shoppers!
The shop closes in 10 minutes.
```

Write each `print` only once, inside the function. The second announcement comes from calling the
function again.
