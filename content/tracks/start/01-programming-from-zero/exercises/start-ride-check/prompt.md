A roller coaster has two rules: riders must be at least 8 years old **and** at least 120 cm tall.
Write a program that asks for the rider's age, then their height in cm, and prints `You can ride!` if
they meet both rules, or `Sorry, not this time.` if they don't.

```text
Age: 10
Height in cm: 135
You can ride!
```

```text
Age: 12
Height in cm: 115
Sorry, not this time.
```

Both answers are whole numbers. Put each question inside `input()`, as in the sample runs, so your
program prints only the answer line. To try it, type the age on the first line of the **Input for Run**
box and the height on the second.
