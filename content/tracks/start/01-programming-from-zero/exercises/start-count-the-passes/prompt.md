A quiz has been marked, and a mark of 50 or more is a pass. The program starts with the list of marks.
Use a `for` loop to print each mark followed by `pass` or `fail`, then print how many passed:

```text
72 pass
45 fail
90 pass
38 fail
66 pass
3 of 5 passed
```

Let the program do the counting: don't type 3 or 5 yourself. If the marks change, every line should
change with them.
