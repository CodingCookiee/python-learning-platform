Write a rocket countdown. Ask which number to count down from, print every number from there down to 1,
then print `Lift off!`. For example, when someone types 5:

```text
Count down from? 5
5
4
3
2
1
Lift off!
```

Use a `while` loop that stops when the count reaches 0. If someone types 0, there's nothing to count, so
the program prints just `Lift off!`. Pass the question to `input()` rather than printing it, so that the
numbers and `Lift off!` are all your program prints.
