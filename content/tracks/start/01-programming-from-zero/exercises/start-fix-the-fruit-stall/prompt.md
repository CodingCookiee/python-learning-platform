A fruit stall sells apples at 3 a kilo. This program asks how many kilos the customer wants and prints
the cost, but it stops with an error as soon as someone asks for 2.5 kilos.

Type `2.5` in the **Input for Run** box, press **Run**, and read the error message. Then fix the
program so that it prints:

```text
How many kilos of apples? 2.5
2.5 kg of apples costs 7.5
```

Whole kilos must still work: an answer of `2` should print `2.0 kg of apples costs 6.0`.
