Write `boxes_needed(items, per_box)` that returns how many boxes the warehouse needs to pack `items`
when each box holds `per_box`. A part-filled box still counts as a box. Import the standard-library
`math` module and use `math.ceil`.

```python
boxes_needed(47, 12)    # 4
boxes_needed(48, 12)    # 4
boxes_needed(0, 12)     # 0
```
