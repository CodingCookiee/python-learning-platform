An order list is kept oldest first. Write `latest_three(orders)` that returns the three most recent
orders, **newest first**:

```python
latest_three(["ORD-1040", "ORD-1041", "ORD-1042", "ORD-1043", "ORD-1044"])
# ["ORD-1044", "ORD-1043", "ORD-1042"]
```

If there are fewer than three orders, return all of them, newest first. Return a new list and leave
`orders` unchanged.
